# `T2.1a` — Freeze the `Pi.Ai.Abstractions` contract

**Wave:** 2  **Delegation fit:** B  **Depends on:** `T1.1` and `T1.2`

## Objective

Port the shared, provider-neutral contracts from the pinned `@earendil-works/pi-ai` package so
provider adapters, the faux provider, and the agent loop can share one stable C# surface. This
packet deliberately freezes the split project described in `docs/solution-layout.md` §2.

## Source (read-only specification)

```
reference/pi/packages/ai/src/types.ts
reference/pi/packages/ai/src/utils/event-stream.ts
reference/pi/packages/ai/src/utils/diagnostics.ts
```

## Target (this packet only)

```
src/Pi.Ai.Abstractions/**
tests/Pi.Ai.Tests/**
```

Do not modify `src/Pi.Ai`, `src/Pi.Ai.Testing`, `Pi.Telemetry`, `Pi.Protocol`, project files, or
`reference/`. C# names use PascalCase while the documented wire names remain in XML/comments and
future provider converters. Preserve the three-state distinction of absent, explicit null, and a
value in optional data where the contract exposes it.

## Deliberate translations

- TypeScript string unions become public string constants plus string-valued properties so custom
  provider/API identifiers remain open-ended.
- TypeBox `TSchema` is represented by `System.Text.Json.Nodes.JsonNode`; the schema emitter is a
  later `Pi.Ai` task.
- Structural message/content/event unions become closed abstract record hierarchies with the
  upstream discriminator values.
- `AsyncIterable` becomes `IAsyncEnumerable`; the event stream also exposes the upstream `result()`
  operation as `Result`.

## Oracle and acceptance

- Port contract, event-stream, diagnostics, content-text, and message construction cases into
  `tests/Pi.Ai.Tests/` without provider calls or skipped tests.
- Build with zero warnings, format verification, and the full solution test suite must pass.
- Record every TypeScript type-level behavior that C# cannot express in the packet/commit summary;
  do not silently invent static guarantees.
