implementation must preserve the pinned upstream v0.84.4 behavior for malformed and partial
JSON, token estimation, context-overflow detection, headers/environment lookup, cancellation,
proxy selection, error normalization, retry classification, and deferred-tool partitioning.

## Deliberate translations

- `AbortSignal` is represented by `CancellationToken`; linked sources own the combined token and
  expose an idempotent cleanup disposable. C# cancellation has no arbitrary JavaScript `reason`,
  so cancellation is surfaced as the standard `OperationCanceledException`/`TaskCanceledException`.
- The `partial-json` dependency is not added. Implement the resumable parser and its repair path
  locally; a valid complete JSON document must use `System.Text.Json`, while incomplete documents
  must return the same best-effort object/array/scalar prefix behavior needed by streaming tool
  calls. No provider-specific parser may be substituted.
- JavaScript object-shape probing in provider error normalization is represented by the explicit
  `ProviderErrorMetadataException` metadata contract plus standard `HttpRequestException` status
  extraction. Provider adapters can populate metadata without reflection or SDK dependencies.
- JavaScript's UTF-16 code-unit hash and UUIDv7 layout are preserved with unchecked 32-bit
  arithmetic and UTF-16 `char` iteration. The UUID generator uses `RandomNumberGenerator` and a
  process-local monotonic timestamp/sequence.
- Node/Bun environment fallback is not applicable to the .NET host; scoped overrides then
  `Environment.GetEnvironmentVariable` are used. Proxy matching and error messages remain
  byte-for-byte compatible where the host provides equivalent inputs.
- The existing `MessageUtilities.ContentText` is reused because it is already part of the frozen
  abstraction contract; duplicating it in `Pi.Ai` would create an ambiguous public API.
- TypeBox's `StringEnum` is represented as a `JsonObject` JSON Schema, not as a runtime generic
  schema object. Validation remains a separate milestone because it is coupled to the agent tool
  execution contract.
