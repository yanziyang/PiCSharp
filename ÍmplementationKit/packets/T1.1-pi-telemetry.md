# `T1.1` — Port `pi-telemetry` to `Pi.Telemetry`

**Wave:** 1  **Delegation fit:** C  **Depends on:** nothing (foundation project)

## Objective

Port the runtime telemetry contract and the reference in-memory recorder from the pinned
`@earendil-works/pi-telemetry` package. This is the foundation consumed by `Pi.Ai.Abstractions`.

## Target (this packet only)

```
src/Pi.Telemetry/**
tests/Pi.Telemetry.Tests/**
```

Do not modify any other project, the solution, build properties, package versions, or
`reference/`. The C# API may expose overloads needed to represent synchronous and asynchronous
callbacks, but the recorded lifecycle, parentage, passivity, attribute merge, status, and snapshot
semantics must match TypeScript.

## Deliberate C# translation

TypeScript's conditional and mapped types (`InferStartAttributes`, `SchemaTelemetrySpan`, and the
typed multi-schema starter) have no direct C# equivalent. Preserve the runtime schema definitions
and provide a runtime-checked starter; document that compile-time exact-key/value inference is not
reproducible in C# and must be enforced by tests or analyzers in a later design task.

  skipped tests.
- `dotnet build PiCSharp.slnx` succeeds with zero warnings.

- `dotnet test PiCSharp.slnx` passes with no skipped tests.
