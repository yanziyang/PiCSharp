# `T3.2` — Port the OpenAI Chat Completions provider adapter

**Wave:** 3  **Delegation fit:** B  **Depends on:** `T2.1b`, `T2.3a`, `T3.1`

## Objective

Port the provider-neutral OpenAI-compatible Chat Completions adapter. It must support ordinary
text turns, multimodal user/tool results, assistant tool-call replay, streamed text/reasoning/tool
call deltas, usage/cost accounting, raw finish reasons, sampling/options merging, and body-rich
error messages over the shared .NET HTTP/SSE transport.

## Deliberate translations

- The provider SDK is replaced by raw JSON over `HttpClient`; no OpenAI NuGet package is added.
- `AbortSignal` is the options cancellation token. The adapter returns a stream immediately and
  reports setup/request/parse failures through a terminal `StreamErrorEvent`.
- OpenAI's JavaScript number values are represented by `JsonNode` numeric values. Tool argument
  fragments are reparsed with the shared partial parser after each delta, and only finalized
  `ToolCall` blocks are retained in the result.
- The large upstream compatibility detector is represented by explicit model compatibility fields
  already carried by `Model.Compatibility`, with standard OpenAI defaults and provider/base-URL
  detection for `max_tokens`, developer roles, reasoning, and streaming usage.
- Provider SDK error retry metadata is unavailable to the raw transport; transient transport
  failures are retried through the existing `ProviderRetryUtilities`, and a metadata exception is
  unwrapped after retry exhaustion so the HTTP body remains visible.

## Oracle and acceptance

- Use an in-memory HTTP handler/custom fetch delegate with deterministic SSE fixtures; never call
  OpenAI or another real provider.
- Assert request JSON for system/user/assistant/tool/image messages, tools, tool choice, token
  fields, model sampling parameters, session cache key, and caller sampling overrides.
- Assert event ordering and final output for text, reasoning, tool calls, usage/cost, finish reason,
  response model, `[DONE]`, malformed streamed tool JSON, provider errors, and cancellation.
- Build with zero warnings/errors, run all generated test executables, and pass full format
  verification before commit/push.
