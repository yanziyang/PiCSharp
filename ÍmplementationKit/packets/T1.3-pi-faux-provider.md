# `T1.3` — Port the deterministic Pi faux provider

**Wave:** 1  **Delegation fit:** A  **Depends on:** `T2.1a` (`Pi.Ai.Abstractions`)

## Objective

Port `reference/pi/packages/ai/src/providers/faux.ts` into `Pi.Ai.Testing`. The faux provider is
the deterministic, token-free provider used by later agent-loop tests and differential fixtures.
Its helper shapes and stream event ordering are part of the test ecosystem contract.

## Source (read-only specification)

```
reference/pi/packages/ai/src/providers/faux.ts
reference/pi/packages/ai/test/faux-provider.test.ts
```

## Target (this packet only)

```
src/Pi.Ai.Testing/**
tests/Pi.Ai.Tests/**
```

Do not modify `Pi.Ai.Abstractions` or any other project. Use the frozen abstractions types and
preserve the upstream defaults, exact error text, response queue semantics, cache accounting,
deferred polling, abort behavior, helper content shapes, and stream event ordering. Never call a
real provider or require credentials.

## C# translations

- TypeScript callbacks become `Func`/`Task` delegates.
- TypeScript's `structuredClone` becomes an explicit deep clone of the JSON/content structures used
  by the faux provider.
- Randomized chunking keeps the upstream UTF-16 slicing behavior; tests use fixed token bounds for
  exact event-order assertions.
- The C# registration owns an explicit disposable/unregister handle; global provider registries are
  not introduced until the `Pi.Ai` models task.

## Oracle and acceptance

- Port all runtime cases from `faux-provider.test.ts` into `tests/Pi.Ai.Tests/` with no skipped tests.
- Target tests, full build, full test suite, and format verification pass with zero warnings.
- The faux provider remains entirely deterministic under fixed token-size settings and token-free.
