# `T3.1` — Port provider HTTP and SSE transport primitives

**Wave:** 3  **Delegation fit:** B  **Depends on:** `T2.3a`

## Objective

Provide the shared .NET transport primitives required by Pi's network provider adapters. The
transport must preserve the upstream SSE framing rules, response metadata callback behavior,
request header merging, cancellation, timeout, and error-body capture without importing provider
SDKs or adding a Node.js dependency.

## Deliberate translations

- `ReadableStream<Uint8Array>` and `TextDecoder` become an async UTF-8 reader over `Stream`; line
  endings accept LF, CRLF, and bare CR. A blank line dispatches one event, data fields join with
  LF, one optional space after a colon is removed, comments are ignored, and a trailing event at
  EOF is flushed exactly once.
- HTTP requests use `HttpClient` and `HttpRequestMessage`. A caller-supplied fetch delegate remains
  authoritative. Default headers are merged case-insensitively, null provider overrides suppress
  defaults, and provider callbacks receive status plus flattened response headers before body
  consumption.
- Request cancellation is linked with timeout cancellation. A non-success response is represented
  by `ProviderRetryException`/`ProviderErrorMetadataException` metadata so higher-level adapters can
  compose the same body-preserving messages.

## Oracle and acceptance

- Port deterministic SSE framing cases from `anthropic-sse-parsing.test.ts`.
- Test custom request delegates, header merging, timeout/cancellation, and status/body capture with

- Build with zero warnings/errors, run the complete generated test executable suite, and verify
