# T4.2 — Pi protocol client and session leases

## Scope

Port the provider-independent client package from the pinned TypeScript package. This milestone
owns byte-transport adaptation, handshake and framed-message lifecycle, correlated requests,
client snapshots, subscriber isolation, and shared/exclusive session leases. It does not own a
transport implementation (Unix sockets are a separate packet) or server-side session execution.

The TypeScript source in `reference/pi/` is read-only and is the specification.

## Required behavior

- Send the framed protocol hello before accepting a server hello; support fragmented and coalesced
  inbound frames through `ServerMessageDecoder`.
- Enforce the configured frame limit in both directions and surface malformed/truncated data as
  protocol failures.
- Track connecting/connected/disconnected state, reject pending requests on terminal failure, and
  permit reconnect through a fresh transport-factory result.
- Correlate request responses, reject command mismatches, convert server errors, and reject
  requests made while disconnected or disposed.
- Apply server/session snapshots monotonically by revision, route events to global and per-session
  listeners, and isolate subscriber failures through `OnListenerError`.
- Implement shared and exclusive leases, attach/detach reference counting, session invalidation,
  cleanup after failed disposal, and per-handle prompt/steer/abort/model/thinking commands.
- Keep all shipping code free of Node.js dependencies and suitable for the repository's nullable,
  warnings-as-errors build.

## Known C# mapping

- TypeScript `ByteTransportFactory` maps to `Func<ByteTransportHandlers, ValueTask<ByteTransport>>`.
- TypeScript unsubscribe functions map to `Action` delegates.
- `Promise` request resolvers map to `TaskCompletionSource` with asynchronous continuations.
- `AsyncDisposable` maps to `IAsyncDisposable`; synchronous `Dispose` is not added to the public
  session lease because detach/dispose may need a protocol round trip.
