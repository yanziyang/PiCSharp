# T3.7 — Port `bedrock-converse-stream`

## Objective

Port the pinned upstream `reference/pi/packages/ai/src/api/bedrock-converse-stream.ts`
to the .NET 10 `Pi.Ai` provider surface with AWS SDK SigV4/credential resolution,
request conversion, streaming events, reasoning, prompt caching, tool use, and
provider diagnostics.

## Specification

The TypeScript source and its Bedrock tests under `reference/pi/` are the read-only
behavioral specification. Relevant upstream tests include:

- `bedrock-convert-messages.test.ts`
- `bedrock-credentials.test.ts`
- `bedrock-custom-headers.test.ts`
- `bedrock-endpoint-resolution.test.ts`
- `bedrock-error-metadata.test.ts`
- `bedrock-models.test.ts`
- `bedrock-raw-stop-reason.test.ts`
- `bedrock-redacted-reasoning.test.ts`
- `bedrock-response-headers.test.ts`
- `bedrock-thinking-payload.test.ts`

## Allowed target paths

- `Directory.Packages.props`
- `src/Pi.Ai/Pi.Ai.csproj`
- `src/Pi.Ai/Providers/Bedrock/BedrockConverseProvider.cs`
- `tests/Pi.Ai.Tests/BedrockConverseTests.cs`
- this packet

Do not modify `reference/` or any other project. The approved
`AWSSDK.BedrockRuntime` dependency in `docs/dependencies.md` may be referenced.

## Compatibility requirements

- Keep `ApiNames.BedrockConverseStream` and Pi wire/data contracts unchanged.
- Preserve the Bedrock Converse request shape and stream event semantics.
- Resolve region/profile/static credentials/bearer token/custom endpoint according
  to the pinned TypeScript behavior, using the AWS SDK for signing and credential
  resolution rather than hand-rolled SigV4.
- Keep provider callbacks (`OnPayload`, `OnResponse`, headers, timeout, cancellation)
  observable and deterministic in tests.
- Never call a real provider from tests; inject a fake Bedrock transport/client.
- Port tests for payload conversion, image/tool results, reasoning, caching, stream
  deltas, stop reasons, errors, and credential/endpoint policy. Skip only genuine
  AWS-integration cases with a specific reason.

## Verification

`dotnet build PiCSharp.slnx --no-restore` must pass with zero warnings, the focused
Bedrock executable tests and the full direct executable test suite must pass, and
`dotnet format PiCSharp.slnx --verify-no-changes --no-restore` must pass.

## Known scope boundary

This packet ports the Bedrock Converse adapter only. Bedrock model catalog data and
the higher-level provider registry are separate milestones unless the existing
provider factory requires a minimal registration change in a later packet.
